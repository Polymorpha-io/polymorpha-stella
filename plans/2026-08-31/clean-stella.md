  - Delete `LegacyKnowledgeProvider:41` branch `candidates<3` fallback; move `LEGACY_KIND_MAP:13` to one-time migration script or gate `if(DB_VERSION===1)` once then remove after TTL.
  - Delete `Embedder:39` wrapper, use `embeddings/EmbeddingService.cosineSimilarity` direct; delete `lib/vector/EmbeddingService:5` re-export, fix `VectorStore:81 import from "@/embeddings/EmbeddingService"` single path.
  - `EmbeddingWorker:31` implement `new Worker(new URL(...,import.meta.url))` + `Comlink` batch `tokenizer batch_encode` or delete file + document Phase 2 defer.

## Edge Cases & Risks

- `KnowledgeService.search()` wire to `vectorStore.search()`: currently brute `knowledgeStore.getAll().filter(kinds/datasetIds/column/includeSuperseded)` + `embeddingService.embed` + `cosine.sort.slice(topK)` inline; moving to `vectorStore.search(queryEmbedding, {kinds,topK})` must preserve `0.3 activeCell +0.2 column +0.2 dataset distance decay` scoring — encapsulate in `vectorStore.search()` or keep `Scorer` wrapper; test `stella-notebook-pipeline.test.ts` TF `activeCell+0.3`.
- Delete `LegacyKnowledgeProvider` `candidates<3` fallback: no `cell` kind exists post-v2 `normalizeKind removes` — verify `grep "cell" KnowledgeStore:15 0`.
- Remove dynamic `import("@/store/useDataStore")` injection: `polymorpha` must `knowledgeProvider.setInput({dataset: useDataStore.getState().raw})` before `KnowledgeService.search()`; add `KnowledgeProviderInput` type; fallback `ragState.profile.dataset empty object` condition `DatasetRepresentationService:76` always false preserved.
- `IdbLruStore` quotas: `EmbeddingCache 20MB/10k` + `clientStore 20MB/10k` + `KnowledgeStore unbounded` — keep distinct DB names `polymorpha-embeddings/vectors/knowledge` to avoid bleed; `trimIfNeeded 20% oldest` preserved.
- `BrainService catch{}` swallowing RAG errors `163,246`: now `throw ValueError Top-level keys` inline `api-connect-zone` per G19 not fallback DataFrame.
- `EmbeddingWorker` stub: sequential `for await modelEmbed` cold start O(n) — Worker batch `tokenizer batch_encode` later; if deleted now, `polymorpha` `EmbeddingService` stays main-thread but 30MB WASM still lazy `import("@xenova/transformers")`.
- Global scale: `ANON_MAX_ROWS 10k` not `403`, `storagePath users/{uid}` vs `anonymous/pending`, `CACHE_TTL 30s LRU 50M CacheService`, `hashDataset SHA-256` hash truth G21, `inflight dedup` preserved.
- `skipLibCheck:false` may surface `@xenova/transformers` typing `node_modules/@xenova` — add `types` if needed or keep `skipLibCheck:true` with justification.
